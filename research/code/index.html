Phase 1 is live locally

Phase 1 (code) is live locally: a deterministic AST guardrail running against terminal tool calls, with graph-based entity/relation extraction currently in development.

The current scope is code reasoning at the terminal hook layer. This is where structural logic transformations are being tested before code touches disk.

Graph extraction is in development

The deterministic AST guardrail is the locally running component. Graph-based entity/relation extraction is currently in development.

These are separate maturity claims: the hook-layer guardrail is live locally; graph extraction is not being presented as a completed capability.

What comes later

Physical reasoning and social reasoning are future research directions and have not started. The long-term bet is to extend the graph logic beyond static code structure.

Physical reasoning would extend that logic to continuous simulation. Social reasoning would examine agent-human interaction structure.
