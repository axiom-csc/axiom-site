Tenthcheck

Shows what an AI coding agent’s edit could break before it lands. A CLI and MCP server for Python repos; plain code analysis, no model.

Found 53 of 60 direct callers (88%) with 0 false positives on starlette, a held-out library.

Beta

Panel

A guard for support chatbots: it checks every reply against your store’s written policy and stops it claiming actions that never happened.

On a held-out set: 0 unbacked “it’s done” claims in 60 replies (5 in 60 with a plain prompt), and no action run without the customer asking.

Shopify integration tested with mocks only; not yet run on a real store.

Beta

Rudis

A Chrome extension for ChatGPT and Claude that flags when the AI changes its answer without a reason, and helps you push back.

Caught 32 of 143 cave-ins in scripted tests on small local models. Not yet measured on real ChatGPT or Claude chats.

Not in the Chrome Web Store yet. The challenge button is reliable; the automatic warning is beta.

Numeric physics, chemistry and appraisal questions where the model is told the rule; answers come from simulation, with fresh parameters per seed.

Llama 3.1 8B: 65 of 140 correct. Mistral 7B: 4 of 140. Only small local models run so far.

Not yet on Zenodo or Hugging Face.
